# components-ref/

Это «пиксельный референс» — куски JSX из визуального прототипа в `variants/strict/screens.jsx`. Они показывают, как выглядят основные компоненты в разметке (отступы, размеры шрифтов, цветовые сигналы).

## Не копируй буквально

В прототипе всё на inline-стилях через объект темы `T`. В Claude Code мы переезжаем на Tailwind + CSS-переменные. Используй маппинг из `spec/components.md` § «Inline → Tailwind».

## Что есть

- `client-card.jsx` — RiskScoreCard, шапка с метриками, табы, секции анкеты, сайд-панель.
- `sanctions.jsx` — таблица санкционных проверок, бейджи similarity, статусы матчей.
- `operations.jsx` — реестр операций с тикером курсов и KYT-флагами.
- `onboarding.jsx` — клиентский шаг онбординга, пример формы.

Все они уже есть в файле `variants/strict/screens.jsx` (в корне проекта). Открой его в редакторе и смотри как готовый источник истины по разметке. Перепиши на TS+Tailwind, следуя:

1. **Структура DOM** — сохраняй (одинаковая иерархия, одинаковые роли).
2. **Размеры и отступы** — переноси на Tailwind утилиты (см. таблицу маппинга).
3. **Цвета** — через `bg-surface`, `text-text-dim` и т.д. (никаких `T.text`!).
4. **Шрифт** — `font-mono` на mono-данных, `font-sans` (по дефолту) на остальном.
5. **Бейджи / KYT-флаги** — единый компонент `<Badge>`, не повторяй inline.

## Где брать пиксели

Если сомневаешься в spacing — открой ComplianceDesk Directions.html в браузере, в DevTools → измерь.
