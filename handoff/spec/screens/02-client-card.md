# 02 · Карточка клиента

**Роут:** `/clients/:id` (редирект на `/anketa`) + 7 вкладок.
**Самый важный экран продукта.**

## Шапка страницы (Header + крошки)

```
КЛИЕНТЫ / ЮЛ-2026-00481                    [Экспорт] [Действия ▾]
ОсОО "Бишкек Крипто Брокер"   ИНН 02408202010256 · Создан 14.03.2026
```

«Действия» — выпадашка:
- Назначить офицера (Drawer)
- Изменить статус (Dialog)
- Запросить документы (Dialog с чек-листом)
- Запустить пересчёт скоринга
- Закрыть дело
- Экспорт PDF полного дела

## Шапка карточки — RiskScoreCard

Полнофункциональный компонент (см. components.md). 6 элементов в одной горизонтальной строке. Это всегда видно вверху, на всех вкладках.

## Сайд-панель (правая колонка 280px)

Видна на всех вкладках, sticky:

1. **StatusPanel** — текущий `<ClientStatusBadge>`, офицер, SLA.
2. **OverridePanel** — показывается ТОЛЬКО если есть `risk.overrideTrigger`. Красная рамка.
3. **AssignmentPanel** — список соисполнителей (чипы), кнопка «+ Добавить».
4. **TagsPanel** — теги клиента (чипы neutral, deletable), кнопка «+ Тег».
5. **QuickActionsPanel** — быстрые действия (одобрить/отклонить/запросить доки) если разрешено ролью и статусом.

## Вкладки

`<Tabs>` с alert-индикатором (красная точка) если есть нерешённые сигналы:

1. **Анкета** — дефолт. Все идентификационные поля.
2. **Документы** — список с превью.
3. **УБО** — конструктор + табличный вид.
4. **Скоринг** — детализация формулы.
5. **Санкции** — журнал совпадений (alert если есть `new` или `in_review`).
6. **Транзакции** — реестр операций клиента + KYT-граф.
7. **История** — аудит-лог.

---

### Вкладка «Анкета»

Аккордеон-секции по главам анкеты:
- **Глава 1. Идентификация ЮЛ/ФЛ** — заполнено 100%.
- **Глава 2. Адреса**
- **Глава 3. Контакты и связь**
- **Глава 4. Деятельность и активы** (только ЮЛ)
- **Глава 5. УБО** (только ЮЛ — кросс-линк на вкладку УБО)
- **Глава 6. Источники средств**
- **Глава 7. Цели использования VASP**

Каждая секция: cd-caps лейбл главы + цвет статуса заполнения + grid 2col полей. Поля в read-only выглядят как input'ы с приглушённой рамкой.

Кнопка «Редактировать» в углу секции → переключает в edit-mode (в форме). На сабмит — PATCH через `lib/api`.

### Вкладка «Документы»

Toolbar: кнопка «Загрузить документ», фильтр по типу.
Grid 3col карточек:
- Превью миниатюра (placeholder если pdf — иконка `FileText`).
- Имя файла, тип, размер.
- Бейдж статуса (`uploaded/verified/rejected/expired`).
- Дата загрузки mono.
- Action menu kebab: скачать, заменить, удалить, история версий.

Drag&drop зона сверху для быстрой загрузки.

### Вкладка «УБО»

Два под-таба «Структура» (граф) / «Список» (таблица). См. отдельный экран `07-ubo-builder.md`.

### Вкладка «Скоринг»

Шапка как RiskScoreCard, но с раскрытыми 4 категориями.
Под каждой категорией — таблица сработавших правил:
- Код (mono): C4.5
- Описание
- Вес
- Балл
- Доказательство (link)
- Override-флаг

Низ — кнопка «Override решение» (если разрешено): открывает Dialog с обоснованием.

### Вкладка «Санкции»

Список карточек `<SanctionMatchCard>` сортированных: new → in_review → false_positive → discharged.
Каждая — действия по разрешению совпадения.

### Вкладка «Транзакции»

Под-табы: «Реестр» (таблица как в 01) / «KYT-граф» (reactflow).
Реестр фильтруется по этому клиенту.
KYT-граф: клиент в центре, контрагенты вокруг, ребра — суммы, цвет ребра — KYT-флаг.

### Вкладка «История»

Вертикальная лента аудит-событий:
- Иконка типа.
- Время mono + actor + summary.
- Раскрывается на клик: detail (`before/after` diff).

Группировка по дням. Фильтр по типу и actor'у.

## Состояния

- **Loading** — каркас + skeleton'ы метрик и табличного контента.
- **Not found** — full-page EmptyState `FileX`, «Клиент не найден» + кнопка назад.
- **Permission denied** — `Lock` EmptyState.
- **Каждая вкладка** имеет свои empty/error.

## Анимации

- Переход между вкладками — fade 120ms (без сдвига).
- RiskScoreCard при пересчёте — flash оранжевым на новые числа (200ms).
- Раскрытие истории — height auto 200ms ease-out.
