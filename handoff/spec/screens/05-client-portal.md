# 05 · Личный кабинет клиента

**Роут:** `/portal` (отдельный layout без Sidebar)
**Видимость:** только клиенту, прошедшему онбординг.

## Лейаут

Простой top-nav (без Sidebar), центрированный контент max-w 960:
```
[ComplianceDesk · Кабинет]   Профиль ▾  Уведомления  Выход
─────────────────────────────────────────────────────────
Доброе утро, Айбек                            Статус: ОДОБРЕН
Личный счёт #ФЛ-2026-00481

[Информация] [Документы] [Запросы] [Лимиты] [История] [Настройки]
```

## Виджеты главной (по умолчанию вкладка «Информация»)

1. **Статус-карточка**: текущий статус крупно, дата одобрения, имя офицера, кнопка «Связаться».
2. **Уровень риска и лимиты** — простыми словами: «Стандартный профиль · Месячный лимит 1 000 000 KGS».
3. **Запрошенные документы** — если есть `awaiting_docs` — баннер orange с кнопкой «Загрузить».
4. **Последние операции** — 5 строк с минимальной таблицей.

## Вкладка «Документы»

Read-only список ранее загруженных документов + кнопка «Загрузить новый» (открывает Dialog с типом).

## Вкладка «Запросы»

Чат-подобный вид: запросы офицера слева, ответы клиента справа, attachments. Композер снизу.

## Вкладка «Лимиты»

Прогресс-бары: «Месячный лимит», «Дневной лимит», «Лимит по контрагенту». Кнопка «Запросить повышение».

## Вкладка «История»

Лента собственных операций и событий профиля.

## Вкладка «Настройки»

- Смена e-mail/телефона (с OTP).
- Двухфакторная аутентификация (TOTP / SMS).
- Подписки на уведомления.
- Удаление аккаунта (с подтверждением).

## Тон

В личном кабинете — менее терминальный, мягче. Toolbar заменён на табы. Иконок больше. Но цветовая палитра та же — пользователь не должен путаться при переходе.

## Адаптив

Mobile-first. Top-nav сворачивается в гамбургер, табы — в горизонтальный скроллер.
