# Состояния

На каждой поверхности с данными должны быть реализованы все 5 состояний. Не пропускай ни одного.

## 1. Loading

**Когда:** первичная загрузка списка или карточки.

**Паттерн:**
- Список → `<Skeleton variant="table-row" />` × 8.
- Карточка → каркас с серыми блоками вместо контента, в той же геометрии.
- НЕ показывай spinner поверх — только в кнопках при действии.

**Анимация:** градиент бежит слева направо, 1.4s linear infinite.

## 2. Empty

**Когда:** запрос успешен, но 0 результатов или сущность ещё не создана.

**Паттерн:**
- `<EmptyState>` по центру.
- Иконка 32px text-ghost (Lucide: `Inbox`, `Search`, `FileText`, `Users`).
- Заголовок 15px semibold.
- Описание 13px text-mute, max 2 строки.
- Опц. CTA-кнопка primary.

**Тексты:**
- Реестр клиентов пуст → «Клиентов пока нет / Создайте первую заявку, чтобы начать»
- Поиск без результатов → «Ничего не найдено / Проверьте формулировку или сбросьте фильтры» + кнопка «Сбросить»
- Документы → «Документы не загружены»
- Транзакции → «Операций за выбранный период нет»

## 3. Error

**Когда:** запрос упал.

**Паттерн:**
- На всю карточку: иконка `AlertCircle` red, заголовок «Не удалось загрузить», описание, кнопка «Повторить».
- На уровне поля формы: рамка `border-red/60`, hint снизу красным.
- На action-кнопках: тост error с описанием.

**Тексты ошибок (общие):**
- «Сервис временно недоступен. Попробуйте через минуту.»
- «Связь с {service} прервана. Данные могут быть неактуальны.»
- «У вас нет прав на это действие.» (см. ниже No Rights)

## 4. No Rights

**Когда:** роль не имеет permission на ресурс/действие.

**Паттерн:**
- Кнопки/пункты меню — disabled с tooltip «Нет прав: требуется роль X».
- Целая страница — `<EmptyState>` с иконкой `Lock`, заголовок «Доступ ограничен», описание и кнопка «Запросить доступ».
- В таблицах: маскированные ячейки `••••` с tooltip «Скрыто: нет прав».

## 5. Validation

**Когда:** инлайн-валидация форм.

**Паттерн:**
- Поле невалидно → красная рамка после `onBlur` (не `onChange`!), error-hint снизу.
- Иконка `AlertTriangle` 12px слева от error-hint.
- Сабмит формы с ошибками → скролл к первому невалидному полю + фокус.
- Над сабмитом — счётчик ошибок: «Найдено 3 ошибки в форме».

**Стандартные сообщения:**
- Required → «Обязательное поле»
- Invalid INN (KG ЮЛ) → «ИНН должен содержать 14 цифр»
- Invalid passport → «Серия — 2 буквы, номер — 7 цифр (AN0123456)»
- Invalid email → «Некорректный e-mail»
- Date in future → «Дата не может быть в будущем»
- Date out of range → «Допустимый диапазон: {from}–{to}»

## 6. Optimistic / In-flight

Для action'ов (одобрить, отклонить):
- Кнопка → `loading=true` со спиннером.
- Локально применить изменение немедленно (e.g. `status: 'approved'`).
- На ошибку — откатить + тост error.

## 7. Permission gating UI

```tsx
<PermissionGate resource="clients" action="approve" fallback={<DisabledTooltip />}>
  <Button>Одобрить</Button>
</PermissionGate>
```

`PermissionGate` — компонент, читает `useAuth()` и либо рендерит детей, либо `fallback`.
