# Локализация и форматы

## Язык

На старте — только русский (`ru-RU`). Все строки — захардкоженные на русском, но через тонкую обёртку `t('key')` для будущего вывода в JSON.

```ts
// src/lib/i18n.ts
import ru from './locales/ru.json';
const dict = ru;
export const t = (key: string, params?: Record<string, string|number>) => {
  let str = dict[key] ?? key;
  if (params) for (const [k, v] of Object.entries(params)) str = str.replace(`{${k}}`, String(v));
  return str;
};
```

`src/lib/locales/ru.json` — плоский dict. Имена ключей: `domain.subdomain.what`, например:
- `clients.list.empty.title`
- `clients.list.empty.description`
- `client.status.in_review`
- `wizard.le.step.identity.title`

## Форматы Кыргызстана

### Дата

| Контекст | Формат | Пример |
|---|---|---|
| Списки, таблицы | `dd.MM.yyyy` | `28.04.2026` |
| Подробно | `d MMMM yyyy` | `28 апреля 2026` |
| С временем | `dd.MM.yyyy HH:mm` | `28.04.2026 14:32` |
| Полное | `dd.MM.yyyy HH:mm:ss` | `28.04.2026 14:32:11` |
| Относительно | `2 минуты назад` (через `formatDistanceToNow`) | |

Использовать `date-fns` с `import { ru } from 'date-fns/locale'`.

### Числа

- Десятичный разделитель — **запятая**: `1 234 567,89`.
- Группировка — **неразрывный пробел**: `1\u00A0234\u00A0567`.
- Через `Intl.NumberFormat('ru-RU')`.

### Деньги

```ts
formatMoney({ amount: 1234567.89, currency: 'KGS' })
// → "1 234 567,89 сом"
formatMoney({ amount: 1500, currency: 'USD' })
// → "$ 1 500,00"
formatMoney({ amount: 0.05432, currency: 'BTC' })
// → "0,05432 BTC"
```

Криптовалюты — символ справа, до 8 знаков после запятой, trailing zeros обрезаются.

### Идентификаторы (KG)

| Сущность | Маска | Длина |
|---|---|---|
| ИНН ЮЛ | `##############` | 14 цифр |
| ИНН ФЛ | `##############` | 14 цифр |
| ОКПО | `########` | 8 цифр |
| Паспорт ID-карта | `AN#######` | 2 буквы + 7 цифр |
| Паспорт серия-номер | `## #######` | старый формат |

Display: всегда mono-шрифтом. ИНН группировать по 4 для читаемости: `0240 8202 0102 56`.

### Адрес

Однострочно: `720040, г. Бишкек, ул. Чуй 168, оф. 412`.

### Телефон

`+996 (___) __-__-__` для мобильных KG. Формат через `libphonenumber-js`.

## Пол / гендер

В формах ФЛ — radio «Мужской / Женский». В отображении — иконка не показываем.

## Множественное число

Используй `Intl.PluralRules('ru-RU')` или `pluralize-ru` для:
- «1 клиент / 2 клиента / 5 клиентов»
- «1 совпадение / 4 совпадения / 7 совпадений»

Удобная утилита:

```ts
plural(n, ['клиент', 'клиента', 'клиентов'])  // → "5 клиентов"
```
