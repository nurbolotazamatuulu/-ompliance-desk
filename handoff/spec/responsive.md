# Адаптив

## Брейкпоинты

```ts
sm:   640   // только утилитарный
md:   768   // tablet старт
lg:   1024  // tablet wide
xl:   1280  // desktop старт ← основной
2xl:  1536  // desktop wide
```

## Логика по экранам

### Sidebar

- `≥ 1280` — открыт, 180px.
- `1024–1279` — свёрнут до 56px (только иконки + tooltip).
- `< 1024` — скрыт; кнопка-гамбургер в Header открывает Drawer слева.

### Header

- Все размеры — sticky.
- На mobile (`< 768`) breadcrumb скрывается, остаётся только заголовок.

### DataTable (Реестр клиентов)

- `≥ 1280` — все колонки видны.
- `1024–1279` — скрываются второстепенные (`tags`, `assignedOfficer`).
- `768–1023` — скрываются ещё и `inn`, `createdAt`.
- `< 768` — таблица превращается в **список карточек**: одна карточка = одна строка, ключевые поля стэком, статус и риск — справа.

### Карточка клиента

- `≥ 1280` — основной контент + правая панель 280px (Status / Override / Assignment).
- `1024–1279` — правая панель уезжает в horizontal-секцию НАД табами.
- `< 1024` — табы сворачиваются в `<Select>` («Выберите раздел»). Контент на всю ширину.

### Wizard онбординга

- `≥ 1024` — две колонки (240px steps + контент).
- `< 1024` — steps превращаются в горизонтальный progress-bar сверху (1/10).

### Личный кабинет клиента

- Mobile-first. На desktop — центрирован, max-w 720.

### Админка

- Стандартный desktop layout. На tablet/mobile показываем предупреждение «Этот раздел оптимизирован для десктопа» (но не блокируем).

## Касания vs клики

- Минимальный hit-target 44×44px на mobile.
- Hover-only взаимодействия → дублировать на long-press / отдельную кнопку.
- DnD только desktop; на mobile — стрелки «вверх/вниз» в карточке.

## Печать

`@media print` — отдельный стиль:
- Принудительно `data-theme="light"`.
- Sidebar и Header скрыты.
- Карточка клиента и журнал санкций — расширены на всю ширину.
- Разрывы страниц перед `<section>` верхнего уровня.
- Тонкие рамки 0.5pt вместо tailwind 1px.
